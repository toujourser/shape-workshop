# 形状工坊（Shape Workshop）

给小学生用的在线 3D 建模工具。把数学里的几何体、化学里的分子、物理里的小实验，做成可以直接拖、转、拼的 3D 模型。

> **当前状态：早期原型。** 目前只完成了几何体模块的第一版（见 `index.html`），分子和物理模块还在设计阶段。

## 为什么做

小学阶段的几何、分子、受力这些概念很抽象，课本上只有平面图。孩子对“动手摆弄”的反应远好于“看公式”，所以我想做一个打开就能玩、不需要任何菜单操作的 3D 工具。

## 设计原则

1. **极简交互**：孩子的注意力很短。每个功能只做一件事，点一下或拖一下就有反馈。
2. **看得见的数字**：调整边长、半径时，体积和表面积的公式与结果同步变化，让孩子自己发现规律。
3. **先对后全**：先把一个模块做扎实，再扩展下一个。

## 当前原型（几何体模块 v0）

- 立方体、圆柱、圆锥、球四种形状
- 滑块调整边长 / 半径 / 高
- 实时显示体积和表面积的公式与数值
- 拖动旋转，支持触屏

本地运行：直接用浏览器打开 `index.html` 即可（需要联网加载 Three.js）。

## 路线图

- [x] 几何体：基础形状 + 实时公式
- [ ] 几何体：展开图动画（立方体、圆柱展开成平面再折回）
- [ ] 分子模块：球棍模型，原子拖拽吸附成键，内置 H₂O、CO₂、CH₄
- [ ] 物理模块：斜面、小球下落、杠杆，可调质量和角度
- [ ] 迁移到 React + TypeScript + Vite + React Three Fiber 工程
- [ ] 物理引擎接入 Rapier，固定步长保证可复现
- [ ] 测试体系：Vitest（公式与吸附逻辑）、Playwright（截图回归）、GitHub Actions CI
